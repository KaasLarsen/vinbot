## Kort svar

**Alkoholfri Sauvignon Blanc** er den anden store «vin-ikke-saft»-stil: **høj syre**, grøn frugt og urter. Reference: **Giesen 0 % Sauvignon Blanc** fra Marlborough (ca. 95–130 kr). Alternativ: Leitz Sauvignon Blanc 0 %.

Se også [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin) og [sauvignon blanc-druen](/guides/sauvignon-blanc-druen).

## Smagsnoter uden alkohol

Klassisk NZ-profil overlever dealkoholisering bedre end mange tror:

- Stikkelsbær, passionsfrugt, lime
- Grønt græs / solbærblad
- Knivskarp syre — det der bærer 0 %-oplevelsen

Loire-agtig (Sancerre-stil) 0 % er **sjældnere** på danske hylder; de fleste flasker er New World-frugtige.

## Flasker værd at kende

| Mærke | Stil | Ca. pris |
|-------|------|----------|
| Giesen 0 % SB | Marlborough, frisk | 95–130 kr |
| Leitz Eins-Zwei-Zero SB | Tysk, citrus/urt | 80–120 kr |
| Andre «0 % sauvignon» | Varierer — smag før bulk-køb | 70–140 kr |

## Mad der elsker stilen

- **Salat, avocado, gedeost, asparges**
- **Rejer, muslinger, let hvid fisk** — [skaldyr og fisk](/guides/alkoholfri-hvidvin-til-skaldyr-og-fisk)
- **Grill-kylling med citron** — [sommermenu](/guides/alkoholfri-hvidvin-til-sommermenu)
- **Terrasse og hverdag** — tæt på pinot grigio-rollen, men med mere bid

Undgå tung cremet sauce uden syre i maden — så falder 0 %-sauvignon fladt. Til fed sauce: se [alkoholfri chardonnay](/guides/alkoholfri-chardonnay).

## Sådan serverer du

**7–9 °C** (lidt koldere end mange drikker den). For varm = græs bliver bittert og sødme træder frem. [Temperatur-guide](/guides/serveringstemperatur-alkoholfri-hvidvin).

## Kort konklusion

Vil du have **frisk, grøn, tør** 0 %-hvid: Giesen eller Leitz sauvignon. Til sushi/thai med lidt sødme: overvej [riesling](/guides/alkoholfri-riesling) i stedet.
