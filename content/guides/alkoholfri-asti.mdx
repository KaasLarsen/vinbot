## Alkoholfri Asti — kort svar

Folk søger **alkoholfri Asti**, når de vil have **sød mousserende 0 %** — samme følelse som **Asti / Moscato d'Asti**, ikke tør champagne-stil. Sortimentet i DK skifter: nogle kæder har **alkoholfri moscato-sparkling**, andre kun **tør 0 %** (Leitz, Torres). Tør 0 % til skål; sød 0 % til **kransekage og brunch**.

Tør kategori: [alkoholfri bobler](/guides/bedste-alkoholfri-bobler). Mimosa: [alkoholfri mimosa](/guides/alkoholfri-mimosa) — der skal du bruge **tør** 0 %, ellers bliver det saft².

## Asti med alkohol vs. 0 %

Klassisk **Asti DOCG** er **sød, lav alkohol (ca. 7–9 %)** og muscat-aroma. **Alkoholfri «Asti-stil»** er oftest **dealkoholiseret moscato eller tilsat aroma** — kvaliteten svinger. Læs **0,0 / 0,5 %** og **ingredienser**. Er det «aromatiseret drik», er det ikke vin.

## Hvornår sød 0 % giver mening

- Kransekage, pavlova, jordbær — se også [vin til dessert](/guides/vin-til-dessert-og-kransekage)  
- Gæster der vil have **sodavands-sødme** i et festglas  
- **Ikke** til østers, chips og parmesan  

Til **nytårsskjål** hvor voksne forventer tørhed: **Leitz sparkling** slår sød 0 %.

## Alternativer

Tør 0 % + **en skive fersken** i glasset, hvis du vil have Asti-association uden sirup. Eller rigtig **Moscato d'Asti** (lav alkohol, ikke 0 %) hvis alkohol er OK i små mængder.
