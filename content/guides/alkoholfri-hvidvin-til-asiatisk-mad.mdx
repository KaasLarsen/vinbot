## Kort svar

Til **sushi og thaimad** er **halvtør eller syrerig** alkoholfri hvid ofte bedre end knastør: lidt **restsødme + høj syre** køler chili og matcher soja. **Leitz Riesling 0 %** er førstevalg; **Torres Muscat** hvis du vil have mere aroma/sødme.

Se [vin til sushi](/guides/vin-til-sushi), [vin til asiatisk mad](/guides/vin-til-asiatisk-mad), [riesling til asiatisk](/guides/riesling-til-asiatisk-mad).

## Hvorfor det virker

1. Chili + alkohol = ekstra varme; uden alkohol bliver heden mere håndterbar.
2. Sukker dæmper capsaicin — derfor halvtør > knastør til strong thai.
3. Syre renser fed fisk og stegte aromater.

| Ret | 0 %-valg |
|-----|----------|
| Sushi / sashimi | Leitz Riesling eller Giesen SB |
| Pad thai / greencurry | Riesling 0 % eller Muscat |
| Vietnamesisk pho / sommeruller | Riesling / let muscat |
| Sichuan / meget stærk | Halvtør muscat — eller øl/alkoholfri bobler |

[Halvtør/sød guide](/guides/halvtor-og-soed-alkoholfri-hvidvin) · [Muscat/Gewürz](/guides/alkoholfri-gewurztraminer-og-muscat).

## Undgå

- Kraftig oaked chardonnay-stil til sushi
- Meget sød «festdrik» uden syre
- Alkoholfri rød til thai (sjældent en gevinst)

## Kort konklusion

Asiatisk 0 %-hvid = **riesling-logik**: syre, frugt, eventuelt diskret sødme. Start med Leitz; skru op for Muscat ved chili.
