## Kort svar

Til **rejer, muslinger og hvid fisk** vælg **tør, syrerig** alkoholfri hvid: **Giesen Sauvignon Blanc 0 %** eller **Leitz Riesling 0 %**. Til **jomfruhummer/fløde** kan en rundere chardonnay-stil virke. Bobler 0 % til **østers og forret**.

Hub: [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin). Klassisk: [vin til fisk og skaldyr](/guides/vin-til-fisk-og-skaldyr).

## Hurtig parringstabel

| Ret | 0 %-valg | Hvorfor |
|-----|----------|---------|
| Rejer / scampi | Sauvignon Blanc | Citrus skærer sødme i skaldyr |
| Muslinger i hvidvinssauce | Tør sauvignon eller riesling | Syre + urter |
| Dampet torsk / rødspætte | Riesling 0 % | Ren, mineralsk |
| Laks | Riesling eller let bobler | Fedme vs. syre |
| Østers | Sparkling 0 % | Perlage + salt |
| Fisk i smørsauce | Chardonnay 0 % (mild) | Lidt mere krop |

Detaljer om druer: [sauvignon](/guides/alkoholfri-sauvignon-blanc), [riesling](/guides/alkoholfri-riesling), [chardonnay](/guides/alkoholfri-chardonnay).

## Tilberedning i gryden

Skal saucen laves med vin: se [alkoholfri hvidvin i madlavning](/guides/alkoholfri-hvidvin-i-madlavning) — 0 % kan erstatte hvidvin til muslinger, men smag til med fond/citrus.

## Servering

**8–10 °C** for stille hvid; sparkling iskold. Undgå søde muscat-stilarter til salt skaldyr — [tør guide](/guides/tor-alkoholfri-hvidvin).

## Kort konklusion

Skaldyr og fisk = **syre først**. Giesen eller Leitz, koldt glas, tør stil. Sød 0 % gem til dessert.
