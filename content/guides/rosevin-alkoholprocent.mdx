## Rosévin alkoholprocent — kort svar

**Rosévin alkoholprocent** er oftest **11–13 % vol.** — samme bånd som tør hvidvin, lidt lavere end kraftig rød. Provence-klassikere ligger ofte **12–13 %**. Sød hvid Zinfandel-rosé og nogle New World-flasker kan ramme **13,5–14,5 %**. Tallet står som **% vol.** på etiketten.

Al vin: [hvor meget alkohol i vin](/guides/hvor-meget-alkohol-i-vin). Genstande: [enheder i glas og flaske](/guides/hvor-mange-enheder-alkohol-i-et-glas-vin).

## Tabel efter stil

| Rosé-stil | Typisk ABV |
|-----------|------------|
| Provence, tør, bleg | **12–13 %** |
| Spansk / Navarra tør | **12–13,5 %** |
| Tysk / østrigsk tør | **11–12,5 %** |
| Sød / white zin-agtig | **9–12 %** (ofte mere sukker) |
| Mousserende rosé (cava, champagne) | **11–12,5 %** |
| Kraftig New World still | **13–14,5 %** |

Farven siger **ikke** alkoholprocent. Mørk rosé kan være 12 %, bleg kan være 13,5 %. Læs etiketten.

## Hvorfor folk spørger

Rosé drikkes **kold og i større glas** om sommeren. Et «stort hæld» på 15–18 cl ved 13 % er **tæt på 1½ genstand**, ikke «bare en let drink». Formel og tabel: [genstande i vin](/guides/hvor-mange-enheder-alkohol-i-et-glas-vin).

Kalorier følger **alkohol + sukker**, ikke den lyserøde farve: [kalorier i vin](/guides/hvor-mange-kalorier-i-vin).

## Bobler og 0 %

**Rosé med bobler** har typisk **samme ABV som stille rosé** i brut-stil. Se [rosévin med bobler](/guides/rosevin-med-bobler).

**Alkoholfri rosé** er max **0,5 %** i EU-mærkning: [alkoholfri rosé](/guides/bedste-alkoholfri-rose).

## Servering

Tør rosé: **8–12 °C**. For varmt smager alkoholen. Åben flaske: 3–5 dage i køl, [åbnet vin](/guides/hvor-laenge-holder-aabnet-vin).
