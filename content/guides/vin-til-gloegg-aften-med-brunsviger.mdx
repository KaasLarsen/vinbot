## Kort svar

Til **brunsviger** på en gløgg-aften:

| | |
|--|--|
| **Default** | Gløgg (gerne hvid eller rød) |
| **Alternativ** | Moscato d'Asti |
| **Undgå** | Tør cabernet |

Start med [gløgg-hubben](/glogg) og [vin til gløgg](/guides/vin-til-glogg).

## Hvorfor

Brunsviger er sød og fed. **Gløgg eller moscato** matcher sødmen; tør rød bliver bitter og flad.

## Pas på

- Gløgg er sød og krydret — den sløver ganen før fin julerød.
- Server små glas; varm alkohol føles stærkere.
- Hold bordvin og gløgg adskilt: én stil til hygge, en anden til maden.
