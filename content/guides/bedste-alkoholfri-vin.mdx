## Hvad er alkoholfri vin?

**Alkoholfri vin** (typisk max **0,5 % ABV** i EU) er **ægte vin**, hvor alkoholen er fjernet efter gæring — ikke druesaft med aroma. De almindelige metoder:

- **Vakuum-destillation** — alkohol fordamper ved lav temperatur.
- **Reverse osmosis** — membran skiller alkohol og vand.
- **Spinning cone** — vakuum + centrifugalkraft.

0,0 % på etiketten er strengere end 0,5 %. Til [graviditet](/guides/alkoholfri-vin-til-graviditet) vælger mange den strengeste mærkning — det er ikke medicinsk rådgivning, bare hvad folk typisk kigger efter.

## God alkoholfri vin til mad

Tænk som ved rigtig vin: **syre, frugt og struktur** — ikke kun sødme.

| Anledning / mad | Stil | Eksempel |
|-----------------|------|----------|
| Skål, brunch, nytår | Bobler | Leitz / Noughty / French Bloom |
| Fisk, sushi, asiatisk | Riesling / sauvignon | Leitz Riesling, Giesen |
| Grill, tapas, terrasse | Rosé eller bobler | Leitz Rosé, Natureo Rosé |
| Pizza, pasta, hverdag | Blød rød | Natureo Red |
| And, lyst kød | Pinot-stil | Leitz Pinot |
| Flæsk / julebord | Bobler + blød rød | [jul](/guides/alkoholfri-vin-til-jul) · [flæskesteg](/guides/alkoholfri-vin-til-flaesketeg) |

Mere: [grill](/guides/alkoholfri-vin-til-grill) · [fest](/guides/alkoholfri-vin-til-fest) · [konfirmation](/guides/alkoholfri-vin-til-konfirmation) · [tapas](/guides/alkoholfri-vin-til-tapas) · [pizza/pasta](/guides/alkoholfri-vin-til-pizza-og-pasta).

Server bobler **6–8 °C**, hvid/rosé **8–10 °C**, rød ca. **12–14 °C**. Varm 0 % smager hurtigt af saft.

## «Bedst i test» — og hvad du skal undgå

Søgningen **alkoholfri vin bedst i test** er stor, fordi kategorien historisk blandede gode vine med sød juice. Der er ikke ét samlet dansk laboratorie-dom — men Leitz, Giesen, Torres Natureo, Noughty og French Bloom er de sikre referencer.

**Undgå:** anonym bulk uden drue/land, «festdrik» med kun aroma, og at dømme hele kategorien på én tynd rød. Ærlig snak: [smager alkoholfri vin godt?](/guides/smager-alkoholfri-vin-godt).

Budget under 100 kr: [alkoholfri under 100 kr](/guides/bedste-alkoholfri-vin-under-100-kr).

## Hvor køber du i Danmark?

- **Supermarked (Netto, Føtex, Bilka, Rema, Meny):** oftest Torres Natureo + kampagne — [alkoholfri i Netto/Føtex](/guides/alkoholfri-vin-i-netto-foetex).
- **Online / vinhandler:** bredest — Leitz, Noughty, Oddbird, French Bloom. Sammenlign på Vinbot.
- **Fest med mange flasker:** køb to stilarter (bobler + hvid/rosé), ikke kun én rød.
