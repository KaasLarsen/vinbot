## Kort svar

**Tør alkoholfri hvidvin** findes — men «tør» på etiketten er **ikke** altid lavt sukker. Alkoholmasken er væk, så selv 10–20 g/L restsukker smager **sødere** end i almindelig vin. Gå efter **høj syre** (riesling, sauvignon) og mærker som **Leitz** og **Giesen**.

Hub: [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin). Baggrund: [hvad er restsukker](/guides/hvad-er-restsukker-i-vin).

## Hvorfor 0 % smager sødere

1. Alkohol giver bitterhed/varme der balancerer sukker.
2. Producenter tilsætter ofte **sukker eller koncentrat** for «krop».
3. Din hjerne forventer vin — får juice-signaler ved høj sødme.

## Sådan finder du den tørreste flaske

| Tjek | Gør dette |
|------|-----------|
| Drue | Riesling / Sauvignon Blanc først |
| Mærke | Leitz, Giesen, Oddbird Blanc frem for anonym muscat |
| Smag i butik | Syre skal «klikke» — ikke kun frugt |
| Næringsdeklaration | Kulhydrat/sukker pr. 100 ml — jo lavere, jo tørrere |
| Undgå | «Sweet», dessert, meget blomstret muscat uden syre |

Se [kalorier i alkoholfri hvidvin](/guides/kalorier-i-alkoholfri-hvidvin) — sukker = kcal når alkoholen er væk.

## Praktiske valg

- **Knastør kandidat:** Leitz Riesling 0 %, Giesen SB 0 % — [riesling](/guides/alkoholfri-riesling), [sauvignon](/guides/alkoholfri-sauvignon-blanc)
- **Halvtør med vilje:** Torres Muscat — [halvtør/sød](/guides/halvtor-og-soed-alkoholfri-hvidvin)
- **Madlavning:** tør 0 % til muslinger/risotto — [madlavning](/guides/alkoholfri-hvidvin-i-madlavning)

## Kort konklusion

Tør 0 %-hvid = **syre først, sukker sist**. Læs næringsinfo, vælg riesling/sauvignon, og smag før du køber kasse.
