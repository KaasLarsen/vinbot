## Kort svar

**Ja** — alkoholfri hvidvin kan bruges til **muslinger, risotto og hvidvinssovs**, men den mangler alkoholens **opløsning af aromaer** og lidt **dybde**. Vælg **tør** 0 %, og vær klar til at **supplere med fond, citron eller eddike**.

Se [hvilken vin til madlavning](/guides/hvilken-vin-til-madlavning-sovs) og [sauce/simren](/guides/sadan-bruger-du-vin-til-sauce-og-simren).

## Ret for ret

| Ret | Virker 0 %? | Tip |
|-----|-------------|-----|
| Muslinger / marinerede skaldyr | Ja | Tør sauvignon/riesling 0 %; smag til med citron |
| Risotto | Ja | Brug samme vin i gryde og glas; ekstra fond |
| Hvidvinssovs / deglacering | Delvist | Start med mindre; tilsæt fond |
| Flambering | Nej | Kræver alkohol |
| Fondue | Ja | Tør 0 % + lidt citronsaft |

[Tør 0 %-hvid](/guides/tor-alkoholfri-hvidvin) · [skaldyr](/guides/alkoholfri-hvidvin-til-skaldyr-og-fisk).

## Hvad du ikke skal gøre

- Bruge sød muscat 0 % til sovs (bliver klæbrig)
- Forvente samme dybde som 12 % vin reduceret ind
- Koge 0 % i timevis uden at smage — aromaer er sårbare

## Kort konklusion

0 %-hvid i gryden er **brugbart til hverdag**. Tør stil + fond/citrus = bedste resultat. Til gæstemiddag hvor saucen er stjernen: overvej klassisk madlavningsvin — eller accepter et lettere udtryk.
