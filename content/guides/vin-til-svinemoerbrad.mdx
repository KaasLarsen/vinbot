## Kort svar

**Vin til svinemørbrad** (indrefilet) handler om **mildt, magert kød**, ofte med fløde, sennep, æble eller svampe. Det er en anden opgave end [flæskesteg](/guides/vin-til-flaesketesteg) eller [pulled pork](/guides/vin-til-pulled-pork). Bred oversigt: [vin til svinekød](/guides/vin-til-svinekoed).

| Sauce / tilbehør | Vin |
|------------------|-----|
| **Fløde / champignon** | Chardonnay eller pinot |
| **Rødvinssauce** | Pinot, Beaujolais, Chianti |
| **Æble / svesker** | Riesling feinherb, gamay |
| **Sennep / dijon** | Riesling, pinot gris, let rød |
| **Grill med BBQ** | Se [grill](/guides/vin-til-grill-og-bbq) — mere frugt |

## Regler

1. **Let til mellemfyldig vin** — undgå tung cabernet.   2. **Syre** — især til fløde og æble.   3. Både rød og hvid virker — afhænger af sauce.   4. Server rød lidt kølig (14–15 °C).

## Rødvin

**Pinot noir** — silke til filet.   **Gamay / Beaujolais** — hverdagsklassiker.   Sangiovese / Chianti — til tomat eller italiensk tilbehør.   Let grenache / Côtes du Rhône — til sennep og lidt sødme.   Rioja Crianza — gæstevenlig blødhed.

## Hvidvin

**Riesling tør / feinherb** — til æble og sød-syrlig sauce.   **Chardonnay** med syre (Mâcon, Chablis-stil) — til fløde/svampe.   Pinot gris / grüner — neutralt match til hverdag.
