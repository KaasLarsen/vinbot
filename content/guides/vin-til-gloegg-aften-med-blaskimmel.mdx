## Kort svar

Til **blåskimmel** på en gløgg-aften:

| | |
|--|--|
| **Default** | Tawny port (efter gløggen) |
| **Alternativ** | Sauternes / sød riesling |
| **Undgå** | Tør, tanninrig cabernet |

Start med [gløgg-hubben](/glogg) og [vin til gløgg](/guides/vin-til-glogg).

## Hvorfor

Blåskimmel vil have **sødme og koncentration**. Gløgg kan være velkomst; skift til tawny port eller sødvin, når osten kommer — se også [portvin til ost](/guides/portvin-til-ost).

## Pas på

- Gløgg er sød og krydret — den sløver ganen før fin julerød.
- Server små glas; varm alkohol føles stærkere.
- Hold bordvin og gløgg adskilt: én stil til hygge, en anden til maden.
