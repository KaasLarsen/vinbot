## Kort svar

**Frizzante** = **let perlage** (blød mousse). **Mousserende / sparkling** = **fuld boble**, fest og skål. Begge findes alkoholfrit; sparkling er stærkere til ritual, frizzante til **uformel hverdag og mad**.

Se [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler) og [alkoholfri champagne/sparkling](/guides/bedste-alkoholfri-champagne).

## Forskellen i praksis

| | Frizzante 0 % | Mousserende 0 % |
|---|---------------|-----------------|
| Bobler | Fine, bløde | Kraftige, vedvarende |
| Glas | Hvidvinsglas ok | Flûte / universal |
| Anledning | Mad, terrasse | Skål, nytår, brunch |
| Eksempel-logik | Perlende hvid | Leitz Sparkling Riesling, Noughty Sparkling |

Juridisk/handelsmæssigt varierer tryk og mærkning — i glasset er **intensiteten** det, du mærker.

## Hvornår frizzante vinder

- Fisk og skaldyr hvor fuld mousse stjæler fokus
- Sommeraften uden «nytårsstemning»
- Gæster der synes sparkling er for formelt

Hvornår sparkling vinder: [fest](/guides/alkoholfri-vin-til-fest), [nytår](/guides/alkoholfri-bobler-til-nytaar), [brunch](/guides/alkoholfri-vin-til-brunch).

## Tip til køb

Kig efter **«sparkling» / «sekt» / «bubbles»** vs. **«frizzante» / «perlende»**. Samme hus (fx Leitz) kan have begge. Hold dem **iskolde**.

## Kort konklusion

Frizzante 0 % = **madvin med prik**. Mousserende 0 % = **fest**. Vælg efter ritual — ikke kun efter «bobler eller ej».
