## Hvorfor Leitz Eins-Zwei-Zero er benchmark

**Leitz** (Weingut Leitz, Rüdesheim/Rheingau–Mosel-området i markedet) laver **rigtig vin først** og fjerner derefter alkoholen. Serien **Eins-Zwei-Zero** (1-2-0) er det mærke danske vinhandlere oftest anbefaler, når nogen spørger efter **alkoholfri vin der ikke smager af saft**.

Det er ikke «bedst i test» i officiel Forbrugerrådet-forstand — men det er **referencen** i bobler og hvid. Sammenlign med andre brands i [bedste alkoholfri mærker 2026](/guides/bedste-alkoholfri-maerker-2026).

| Flaske | Type | Ca. pris (DK) | Bedst til |
|--------|------|---------------|-----------|
| **Sparkling Riesling** | Bobler | 80–120 kr | Skål, brunch, tapas, fest |
| **Riesling** | Hvid | 75–110 kr | Fisk, salat, asiatisk |
| **Rosé** | Rosé | 75–110 kr | Terrasse, grill, let mad |
| **Pinot Noir** | Rød | 110–150 kr | And, lyst kød, pizza «med stil» |

## Sparkling Riesling — start her

**Leitz Eins-Zwei-Zero Sparkling** er kategoriens sikreste køb: **tør**, citrus/æble, fin mousse. Kulsyren kompenserer for manglende alkohol — derfor «virker» bobler ofte bedre end still-rød i 0 %-klassen.

- **Temp:** 6–8 °C.  
- **Glas:** flute eller hvide vineglas.  
- **Mad:** ostron-stil forret, sushi, chips & dips, nytårsskål.

Mere bobler-kontekst: [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler). Budget-alternativ: Torres Natureo Sparkling i [under 100 kr](/guides/bedste-alkoholfri-vin-under-100-kr).

## Still Riesling — mest «vin» i hvid

**Leitz Riesling 0 %** har **syre og mineral** der ligner tysk riesling mere end de fleste 0 %-hvide. Det er derfor den ofte vinder over aromatiske muscat-typer, når målet er «ikke saft».

- **Temp:** 8–10 °C.  
- **Mad:** dampet fisk, cæsarsalat, thai (mild), gedeost.  
- **Undgå:** meget sød dessert — syren kan føles skarp.

Se [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin).

## Rosé — tør sommerstil

**Leitz Rosé 0 %** er tørrere end mange Natureo-roséer: jordbær uden sukkerbomber. God til [grill](/guides/alkoholfri-vin-til-grill), tapas og brunch.

## Pinot Noir — bedste 0 %-rød (med forbehold)

**Leitz Pinot 0 %** er blandt de bedste alkoholfri røde i DK — kirsebær, lidt krydderi, mere struktur end Torres Natureo Red. Alligevel: **forvent ikke Bourgogne**. Server **ca. 12–14 °C**, og hav bobler klar hvis glasset føles tyndt til tung sauce.

Ærlig guide: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin).

## Servering — små ting der redder glasset

1. **Køl grundigt** — varm 0 % smager fladt.  
2. **Samme glas** som alkoholisk vin.  
3. **Drik bobler inden for ~24 t** efter åbning.  
4. **Pinot:** lidt mad med fedme (ost, sauce) blødgør oplevelsen.
