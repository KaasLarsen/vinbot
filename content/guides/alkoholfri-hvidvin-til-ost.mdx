## Kort svar

**Milde oste** (brie, mozzarella, unge gedeoste) → **tør sauvignon eller pinot grigio 0 %**. **Aromatiske/kraftige** (moden cheddar, munster-agtig) → **muscat eller rund chardonnay 0 %**. **Blåskimmel** → sødere 0 % eller skip vin — port-logik uden alkohol er svær.

Klassisk ost: [vin til brie](/guides/vin-til-brie-og-camembert), [portvin til ost](/guides/portvin-til-ost).

## Parringstabel

| Ost | Alkoholfri hvid | Note |
|-----|-----------------|------|
| Frisk gedeost | Giesen SB 0 % | Syre vs. syre |
| Brie / camembert | Noughty Chardonnay eller tør riesling | Blød fedme |
| Gruyère / comté-agtig | Riesling 0 % | Frugt skærer salt |
| Cheddar | Muscat eller fyldig 0 %-hvid | Lidt sødme hjælper |
| Blåskimmel | Halvtør muscat / sød 0 % | Eller dessertvin-alternativ |
| Ostebord blandet | Én tør + én aromatisk | To flasker slår én kompromis |

## Praktiske tips

- Server osten **ikke iskold**; vinen **8–10 °C**.
- Salt ost + sød vin er klassisk — virker også i 0 %.
- Undgå meget tanninrig alkoholfri rød til bløde hvide oste.

## Kort konklusion

Ostebord uden promille: **sauvignon til gedeost**, **chardonnay/muscat til bløde og kraftige**. Hold det enkelt — to stilarter dækker de fleste brætter.
