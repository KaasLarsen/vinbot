## Kort svar

**Alkoholfri Pinot Noir** (tysk: **Spätburgunder**) er den **mest succesfulde 0 %-rødvinsdrue** i Danmark — blødere tannin, rød frugt og syre, der kompenserer bedre for manglende alkohol end cabernet eller shiraz. Referenceflasken: **Leitz Eins-Zwei-Zero Pinot Noir** (ca. 110–150 kr).

Hub: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin) · Mærke: [Leitz Eins-Zwei-Zero](/guides/leitz-eins-zwei-zero).

## Hvorfor pinot vinder i 0 %-rød

Alkohol giver normalt **krop, varme og blødhed** til tannin. Uden den bliver hårde druer (cabernet, ung syrah) let **tynde og bitre**. Pinot har:

- **Lavere tannin** → mindre «bark» uden alkohol.  
- **Rød bærfrugt** (kirsebær, hindbær) der stadig genkendes.  
- **Syre**, der holder glasset friskt ved **12–14 °C**.

**Spätburgunder** er samme drue som Pinot Noir — tysk navn. På alkoholfri **rosé** ser du ofte Spätburgunder-base; på **rød 0 %** er det typisk solgt som Pinot Noir (Leitz).

## Bedste flasker at starte med

1. **Leitz Eins-Zwei-Zero Pinot Noir** — kategoriens benchmark: kirsebær, let krydderi, blødere tannin end de fleste 0 %-røde.  
2. **Oddbird Red / Rouge** — ikke altid 100 % pinot, men samme «elegant rød»-slot; se [Oddbird](/guides/oddbird-alkoholfri-vin).  
3. **Giesen 0 % Merlot** — alternativ hvis pinot er udsolgt: blødere, mindre krydderi.

Undgå anonyme «alkoholfri rødvin» uden drue/producent. Budget-hverdag uden pinot-ambition: **Torres Natureo Red** (garnacha) — se nedenfor.

## Pinot vs garnacha vs «tung» 0 %-rød

| Stil | Eksempel | Bedst til | Forventning |
|------|----------|-----------|-------------|
| **Pinot / Spätburgunder** | Leitz Pinot | And, svampe, «vinagtig» pizza | Mest elegance |
| **Garnacha** | Torres Natureo Red | Pizza, pasta, pølser | Blød hverdag |
| **Cabernet / tung stil** | Vintense Zero Cabernet | Grill med forbehold | Mere struktur, ofte tørrere finish |

Tungere stilarter (cabernet/shiraz) og egetræsekstrakt: uddybes i [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin).

## Madparring

- **And, lyst kød, svampe** — klassisk pinot-logik uden alkohol.  
- **Pizza «med stil»** / pasta med ragù — bedre end cabernet-0 %; til simpel tomat-pizza vinder Natureo ofte på frugt. Se [alkoholfri vin til pizza og pasta](/guides/alkoholfri-vin-til-pizza-og-pasta).  
- **Flæskesteg** — pinot som det blødeste røde kompromis: [alkoholfri til flæskesteg](/guides/alkoholfri-vin-til-flaesketeg).  
- **Tung bøf / vildt** — forventningerne er for høje; vælg bobler eller alkoholisk vin i stedet.

## Servering

- **12–14 °C** — køligere end klassisk rød; dæmper sødme og tynd krop.  
- Almindeligt **rødvinsglas**.  
- Drik inden for **2–3 dage** efter åbning (køleskab + prop).

## Kort konklusion

Start med **Leitz Pinot Noir 0 %**, hvis du vil have alkoholfri rød der smager mest af **vin**. Til ren hverdags-pizza er garnacha (Natureo) ofte nok — pinot er opgraderingen.
