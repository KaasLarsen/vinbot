## Kort svar

Til **sprød salat** og **kylling på grillen**: **Sauvignon Blanc 0 %** (Giesen) eller **Pinot Grigio 0 %** til uformelt. Til **grill med citron/urter** vinder sauvignon; til **glaze/sød marinade** en riesling 0 %.

Se [alkoholfri vin til grill](/guides/alkoholfri-vin-til-grill), [vin til salat](/guides/vin-til-salat), [rosevin til grill](/guides/rosevin-til-grill).

## To sommer-menuer

**Menu A — let**
- Salat med gedeost → Giesen SB 0 %
- Grillkylling med citron → samme flaske
- Jordbær til dessert → skift til muscat eller bobler

**Menu B — havefest**
- Velkomst: frizzante/sparkling 0 % — [frizzante](/guides/alkoholfri-frizzante-hvidvin)
- Hovedret: pinot grigio 0 % eller riesling
- Ost: se [osteguide](/guides/alkoholfri-hvidvin-til-ost)

## Temperatur i varmen

Hold flaskerne i **isvand** — sommerterrasser dræber 0 %-hvid hurtigt. Mål: **7–9 °C**. [Serveringstemperatur](/guides/serveringstemperatur-alkoholfri-hvidvin).

## Kort konklusion

Sommermenu uden alkohol = **kold sauvignon til salat og citron-grill**, pinot grigio til afslappet havebord. Én god 0 %-hvid dækker det meste.
