## Kort svar (med disclaimer)

**Alkoholfri vin kan have mere restsukker end du forventer**, fordi producenter ofte tilsætter most eller sukker for at give kroppen tilbage efter de-alkoholisering. Til dig der tæller kulhydrat — inkl. mange med diabetes — er nøglen: **læs etiketten, vælg tør stil, undgå «festdrik»**.

**Dette er ikke medicinsk rådgivning.** Tal med din læge eller diabetessygeplejerske om alkohol, 0 %-drikke og dit eget blodsukker. Vinbot anbefaler flasker efter smag og etiket — ikke som behandling.

Relateret: [kalorier i alkoholfri vin](/guides/kalorier-i-alkoholfri-vin) · [tør alkoholfri hvidvin](/guides/tor-alkoholfri-hvidvin) · [hvordan fremstilles alkoholfri vin](/guides/hvordan-fremstilles-alkoholfri-vin).

## Hvorfor 0 % ofte smager sødere

1. **Alkohol fjernes** → krop, varme og «tørhed» falder.  
2. Producenten **tilsætter druesaft/most** eller justerer sødme.  
3. Uden alkohol føles den samme restsukker **sødere** på tungen.

Derfor kan to flasker begge hedde «alkoholfri», mens den ene er **knastør** og den anden nærmer sig **saft**.

## Hvad du skal kigge efter på etiketten

| Signal | Bedre valg | Drop |
|--------|------------|------|
| Stilord | **Brut**, tør, riesling, sauvignon | «Festdrik», aroma uden vintype |
| Næringsdeklaration | Lavt **kulhydrat/sukker pr. 100 ml** | Ingen tal + meget sød smag |
| Producent | Leitz, Noughty, French Bloom, Oddbird, Torres (tjek stil) | Anonym carton |
| ABV | 0,0 % / alkoholfri | Irrelevantet med sød «glögg-agtig» 0 % |

Tommelfinger i glasset: **høj syre + lav sødme** = typisk lavere kulhydrat-oplevelse. Se [smager alkoholfri vin godt?](/guides/smager-alkoholfri-vin-godt).

## De mest «knastørre» udgangspunkter i DK

Ingen officiel glykæmisk rangliste — men disse stilarter er **mest konsistent tørre** i markedet:

1. **Leitz Eins-Zwei-Zero Sparkling Riesling** og **still Riesling** — syre først, mindst «saft». [Leitz-guide](/guides/leitz-eins-zwei-zero) · [alkoholfri Riesling](/guides/alkoholfri-riesling).  
2. **Noughty Sparkling Chardonnay** — ofte kommunikeret med lav kcal; **tjek stadig sukker**. [Noughty](/guides/noughty-alkoholfri-vin).  
3. **French Bloom / Oddbird** premium sparkling — tørere profil end discount-bobler. [French Bloom](/guides/french-bloom-alkoholfri-vin) · [Oddbird](/guides/oddbird-alkoholfri-vin).  
4. **Tør 0 %-sauvignon** (fx Giesen 0 %) — græs/citrus, lav sødme. [Sauvignon Blanc 0 %](/guides/alkoholfri-sauvignon-blanc).

**Vær mere kritisk over for:** sød muscat, «halvtør» hverdags-0 %, mange billige røde og private label uden producent. Se [halvtør og sød 0 % hvid](/guides/halvtor-og-soed-alkoholfri-hvidvin).

## Bobler, hvid, rosé, rød — sukker-risiko

| Type | Typisk risiko | Tip |
|------|---------------|-----|
| **Tør bobler** | Lav–mid | Bedste start |
| **Tør hvid (riesling/SB)** | Lav–mid | Læs «tør» vs restsødme |
| **Rosé** | Mid | Natureo kan være blødere/sødere end Leitz |
| **Rød** | Mid–høj | Frugt kompenserer ofte med sødme — [rødvin-guide](/guides/bedste-alkoholfri-rodvin) |

## Kalorier ≠ automatisk «sikkert for blodsukker»

Lav **kcal** hjælper ikke, hvis kulhydratet er koncentreret sukker. Brug kalorie-guiden som **overblik**, etiketten som **beslutning**: [kalorier i alkoholfri vin](/guides/kalorier-i-alkoholfri-vin).

Graviditetsdiabetes nævnes kort i [0 % hvid til gravide](/guides/alkoholfri-hvidvin-til-gravide) — igen: følg sundhedsfaglig råd.

## Kort valg

1. **Vil have lav sødme** → Leitz Riesling / Sparkling.  
2. **Brunch uden saftbomber** → Noughty Sparkling + tjek etiket.  
3. **Fest / gave, tør stil** → Oddbird eller French Bloom.  
4. **Usikker på hylden** → drop anonym «alkoholfri rød» uden sukkertal.
