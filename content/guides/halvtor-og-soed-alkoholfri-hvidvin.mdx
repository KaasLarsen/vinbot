## Kort svar

**Halvtør og sød alkoholfri hvidvin** er genial til **velkomst, brunch og dessert** — og til stærk asiatisk mad — men dårlig som «tør hverdagshvid». Tænk **Torres Natureo Muscat**, aromatiske cuvéer og [alkoholfri Asti](/guides/alkoholfri-asti).

Tør alternativ: [tørheds-guiden](/guides/tor-alkoholfri-hvidvin).

## Hvornår sødme er en fordel

- Velkomstglas hvor gæster forventer «lidt fest»
- Frugtdessert, kager, blåskimmel (forsigtigt)
- Thai/chili hvor sukker + syre køler hede — [asiatisk](/guides/alkoholfri-hvidvin-til-asiatisk-mad)
- Brunch — [alkoholfri brunch](/guides/alkoholfri-vin-til-brunch)

## Stilguide

| Stil | Eksempel | Brug |
|------|----------|------|
| Aromatisk muscat | Torres Natureo Muscat | Velkomst, salat med frugt |
| Perlende sød | Asti-agtig 0 % | Dessert, toast |
| Halvtør riesling | Visse 0 %-rieslinger | Asiatisk mad |

Bobler med sødme: [alkoholfri bobler](/guides/bedste-alkoholfri-bobler) og [mimosa](/guides/alkoholfri-mimosa).

## Pas på kalorier og «saft»

Sød 0 % kan nærme sig sodavand i kcal — [kalorier](/guides/kalorier-i-alkoholfri-hvidvin). Server **kold** (6–8 °C) så sødmen ikke dominerer.

## Kort konklusion

Vælg sød/halvtør **med vilje** til anledningen — ikke som erstatning for tør hvid til fisk. Muscat og Asti-stil er de sikre kort.
