## Målet med denne guide

En **praktisk metode** til at sammenligne alkoholfri øl og vin — uden at antage, at 0 % er «sundt» eller kaloriefrit.

Baggrundstal: [kalorier i alkohol vs. alkoholfri](/guides/kalorier-i-alkohol-vs-alkoholfri).  
Sukker i 0 % vin: [hvor meget sukker i alkoholfri vin?](/guides/hvor-meget-sukker-i-alkoholfri-vin).

## Hvorfor «0,0 %» ikke betyder få kalorier

**0,0 %** (eller «alkoholfri») beskriver **alkohol**. Kalorierne i alkoholfri drikke kommer især fra **kulhydrat og sukker** (4 kcal/g ifølge EU 1169/2011). To flasker med samme alkoholprocent kan derfor have **meget forskellige** kcal-tal.

## Trin-for-trin metode

### 1. Find kcal pr. 100 ml

Det er din **fælles målestok**. Ignorer midlertidigt smagsbeskrivelser og «light»-ord.

### 2. Se på portionsstørrelsen

| Drik | Typisk portion | Omregning |
|------|----------------|-----------|
| Vin | 12,5 cl | × 1,25 |
| Vin | 15 cl | × 1,5 |
| Øl | 33 cl | × 3,3 |
| Øl | 50 cl | × 5,0 |

**Eksempel:** 22 kcal/100 ml × 3,3 ≈ **73 kcal** pr. 33 cl.

### 3. Se på sukker

Find **«heraf sukkerarter»**. Lav kcal med højt sukker kan stadig være relevant, hvis du tæller kulhydrat. Mere: [sukker i alkoholfri vin](/guides/hvor-meget-sukker-i-alkoholfri-vin).

### 4. Se på kulhydrater

I alkoholfri øl er kulhydrat ofte den **primære** energikilde. Sammenlign kulhydrat/100 ml mellem kandidater — især ved flere øl: [tager man på af alkoholfri øl?](/guides/tager-man-paa-af-alkoholfri-oel).

### 5. Se på alkoholprocenten

«Alkoholfri» kan være **0,0–0,5 %** i dansk praksis ([Fødevarestyrelsen](https://www.altinget.dk/foedevarer/ministersvar/121560)). Har du behov for reelt nul, vælg produkter der eksplicit er **0,0 %** og læs deklarationen.

### 6. Sammenlign produkter side om side

Brug samme skema til 2–3 flasker:

| Felt | Flaske A | Flaske B |
|------|----------|----------|
| kcal/100 ml | | |
| Portion (ml) | | |
| kcal/portion | | |
| Sukkerarter/100 ml | | |
| Kulhydrat/100 ml | | |
| % vol. | | |
| Stil (tør/sød) | | |

Vinderen på kalorier er ikke nødvendigvis vinderen på **smag**. Beslut dig for prioriteten.

## Hurtige tommelfingre (med forbehold)

- **Tør/brut bobler og syrlig hvid 0 %** er ofte et godt *startsted* — men verificér tal.
- **Søde «festdrikke»** uden vintype: højere risiko for sukker/kcal.
- **Øl i 50 cl:** selv «lave» kcal/100 ml summerer hurtigt.

Vin-forslag (stil, ikke facit): [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler) · [tør alkoholfri hvidvin](/guides/tor-alkoholfri-hvidvin) · [Leitz](/guides/leitz-eins-zwei-zero) · [Noughty](/guides/noughty-alkoholfri-vin).

## Når kalorier ikke er hovedmålet

Nogle vælger alkoholfrit for **søvn, bil, graviditet eller social inkludering**. Så er kalorier sekundære — men etiketten er stadig nyttig.
