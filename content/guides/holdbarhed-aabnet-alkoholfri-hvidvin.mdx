## Kort svar

**Åbnet alkoholfri hvidvin** holder typisk **3–5 dage** i køleskab med prop — ofte **kortere** end alkoholisk hvid, fordi alkoholen ikke længere hæmmer bakterier/gær på samme måde. Sparkling 0 %: **1–2 dage** med stopper.

Relateret: [hvor længe holder hvidvin](/guides/hvor-laenge-holder-hvidvin), [opbevaring](/guides/opbevaring-af-vin-temperatur-og-aabnet-flaske).

## Tommelfinger

| Type | Åbnet i køl | Tegn på «færdig» |
|------|-------------|------------------|
| Tør 0 %-hvid | 3–5 dage | Flad, æbleeddike, muglugt |
| Sød 0 %-hvid | 2–4 dage | Klistret sødme, gæring |
| Sparkling 0 % | 1–2 dage | Ingen bobler, kedelig |
| Uåbnet | Til best-before / 12–18 mdr. typisk | Varme-skadet |

## Sådan får du flest dage

1. **Køl med det samme** efter åbning.
2. **Tæt prop** / vakuumpumpe hjælper lidt.
3. Undgå at lade flasken stå fremme i timevis.
4. Lugt og smag dag 3 — ved tvivl: brug til [madlavning](/guides/alkoholfri-hvidvin-i-madlavning) eller kassér.

## Kort konklusion

Regn med **op til ca. en arbejdsuge** for stille 0 %-hvid i køl — ikke to uger. Køb flaskestørrelse I kan nå at drikke.
