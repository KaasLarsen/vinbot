## Kort svar

**Alkoholfri Riesling** er ofte den **stærkeste 0 %-hvid**: høj **syre** og citrus/æble-noter maskerer fraværet af alkohol bedre end bløde, sødmefulde hvide. Reference i Danmark: **Leitz Eins-Zwei-Zero Riesling** (ca. 75–110 kr).

Hub: [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin). Produktion: [hvordan fremstilles alkoholfri vin](/guides/hvordan-fremstilles-alkoholfri-vin).

## Hvad kendertegner stilarten?

Ægte riesling (Mosel, Rheingau, Pfalz) bygger på **syre**, **mineral** og frugt — ikke på alkoholens «varme». Når alkoholen fjernes via vakuumdestillation, bliver den bedste 0 %-riesling stadig **sprød, citrusagtig og mineralsk**. Undgå flasker uden producent, der smager af **druesaft**.

| Signal på etiketten | Betydning |
|---------------------|-----------|
| Riesling / Eins-Zwei-Zero | Drue + stil — godt tegn |
| «White» uden drue | Ofte blød cuvée — tjek sukker |
| Max 0,5 % ABV | Lovlig «alkoholfri» i DK/EU |

## Bedste flasker at starte med

1. **Leitz Eins-Zwei-Zero Riesling** — kategoriens benchmark; citrus, grønt æble, skifer-agtig finish. Se [Leitz-guiden](/guides/leitz-eins-zwei-zero).
2. **Leitz Sparkling Riesling 0 %** — samme DNA med bobler til aperitif ([alkoholfri bobler](/guides/bedste-alkoholfri-bobler)).
3. Andre tyske 0 %-rieslinger på hylden — sammenlign altid **syre vs. sødme** i glasset, ikke kun prisen.

## Madparring

- **Sushi, sashimi, poke** — syren renser fed fisk og soja.
- **Thai, vietnamesisk, let chili** — restsødme (hvis der er lidt) + syre balancerer hede; se også [alkoholfri hvidvin til asiatisk](/guides/alkoholfri-hvidvin-til-asiatisk-mad).
- **Let fisk, gedeost, asparges** — klassisk riesling-logik uden promille.

Server **8–10 °C**. Detaljer: [serveringstemperatur](/guides/serveringstemperatur-alkoholfri-hvidvin).

## Tør eller lidt sød?

Mosel-riesling kan have **restsukker**. På 0 % er det ekstra vigtigt: høj sødme uden syre = saft. Vil du have **knastør**: vælg Leitz-stilen og læs [tørheds-guiden](/guides/tor-alkoholfri-hvidvin). Mere aromatisk/sød: [halvtør og sød](/guides/halvtor-og-soed-alkoholfri-hvidvin) eller Torres Muscat.

## Kort konklusion

Start med **Leitz Riesling 0 %**, server kold, og match til fisk og asiatisk. Så får du 0 % der smager af **vin**, ikke juice.
