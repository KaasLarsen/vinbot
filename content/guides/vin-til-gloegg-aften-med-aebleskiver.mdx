## Kort svar

Til **æbleskiver** på en gløgg-aften:

| | |
|--|--|
| **Default** | Gløgg selv (rød eller hvid) |
| **Alternativ** | Moscato d'Asti eller sød cider |
| **Undgå** | Tør cabernet / stram rød |

Start med [gløgg-hubben](/glogg) og [vin til gløgg](/guides/vin-til-glogg).

## Hvorfor

Æbleskiver er søde og fede. **Gløggen er drikkken** — krydderi og varme matcher kanel og æble. Vil I have noget ved siden af, vælg sød, let boblende moscato eller cider, ikke tør tanninrød.

## Pas på

- Gløgg er sød og krydret — den sløver ganen før fin julerød.
- Server små glas; varm alkohol føles stærkere.
- Hold bordvin og gløgg adskilt: én stil til hygge, en anden til maden.
