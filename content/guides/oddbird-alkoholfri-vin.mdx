## Oddbird — kultmærket mellem midpris og premium

**Oddbird** er det svenske 0 %-mærke, der ofte dukker op, når nogen søger **alkoholfri champagne-stil** uden at gå helt op i French Bloom-pris. Flaskerne er **design-tunge**, stilen er **tør og vinagtig**, og serien dækker både **bobler, hvid og rød**.

Samlet mærke-landskab: [bedste alkoholfri mærker 2026](/guides/bedste-alkoholfri-maerker-2026) · [alkoholfri hub](/alkoholfri-vin).

| Flaske | Type | Ca. pris (DK) | Bedst til |
|--------|------|---------------|-----------|
| **Blanc de Blancs** / Sparkling | Bobler | 120–170 kr | Fest, skål, gave |
| **Domaine de la Prade** (hvid) | Hvid | 140–200 kr | Fisk, ost, gæster |
| **Oddbird Red / Rouge** | Rød | 140–220 kr | And, svampe, pizza «med stil» |

## Blanc de Blancs — flagskibet

**Oddbird Blanc de Blancs** er den flaske folk typisk mener, når de siger «Oddbird»: **chardonnay-base**, fin mousse, elegant og tørere end mange discount-0 %. Mindre «show» end [French Bloom](/guides/french-bloom-alkoholfri-vin), mere klassisk hvid sparkling end Torres Natureo.

- **Temp:** 6–8 °C.  
- **Glas:** flute eller hvide vineglas.  
- **Anledning:** [fest](/guides/alkoholfri-vin-til-fest), [nytår](/guides/alkoholfri-bobler-til-nytaar), [konfirmation](/guides/alkoholfri-vin-til-konfirmation).

Mere bobler: [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler). Premium-segment: [alkoholfri champagne](/guides/bedste-alkoholfri-champagne).

## Still hvid og rød

**Oddbird hvid** (ofte Domaine de la Prade) ligger i den mere komplekse ende af 0 %-hvid — god når gæsterne forventer mere end «frugtjuice». Se også [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin).

**Oddbird Red / Rouge** er blandt de mere fyldige 0 %-røde i DK: mere krop end Torres Natureo, stadig ikke Bourgogne. Server **12–14 °C**. Ærlig kontekst: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin) · [alkoholfri Pinot Noir](/guides/alkoholfri-pinot-noir).

## Hvor køber du Oddbird i DK?

Primært **online vinhandlere** og udvalgte specialty/super. Sjældnere i Netto end Natureo — se [Netto/Føtex/Bilka/Meny](/guides/alkoholfri-vin-i-netto-foetex).

**Pris-tip:** Oddbird ligger **over** Leitz/Torres til hverdag og **under** French Bloom til gave. Køb Natureo til volumen; Oddbird til **velkomst og skål**.

## Kort valg

1. **Skål / fest** → Blanc de Blancs.  
2. **Gave / nytår med budget** → Oddbird før French Bloom.  
3. **Mest «vin» til hverdagspris** → Leitz Sparkling eller Riesling.  
4. **Rød til and/pizza** → Oddbird Rouge eller Leitz Pinot.

## Servering

- Køl bobler til **6–8 °C**.  
- Åbn tæt på servering — mousse falder hurtigere end i alkoholisk champagne.  
- Brug **samme glas** som resten af bordet.
