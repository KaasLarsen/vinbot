## Alkoholfri vin til tapas — ét bord, tre stilarter

**Alkoholfri vin til tapas** skal kunne **salt, fedme, syre og mange små retter** uden at smage af saft. Den sikreste 0 %-strategi er den samme som med alkohol: **rosé + tør hvid + bobler**. Én tung 0 %-rød til hele brættet er den mest almindelige fejl.

Klassisk (med alkohol): [vin til tapas](/guides/vin-til-tapas). Her er 0 %-oversættelsen.

| Tapas | Bedste 0 %-valg | Hvorfor |
|-------|-----------------|---------|
| Oliven, mandler, chips | Bobler | Mousse renser salt |
| Jamón, chorizo, paté | Rosé eller bobler | Frugt + syre mod fedme |
| Rejer, blæksprutte, ceviche-agtigt | Tør hvid (SB/riesling) | Syre og citrus |
| Manchego, gedeost | Bobler eller riesling | Skærer fedme |
| Tomatbrød, pan con tomate | Rosé eller frisk hvid | Syre møder syre |
| Kødalbóndigas / let rødt | Blød rød (Natureo) eller pinot | Kun hvis resten af bordet er kødtungt |

## Rosé 0 % — tapasbordets default

**Alkoholfri rosé** er det mest alsidige tapasglas: jordbær, syre, kølig servering. Den tåler **skinke, ost, grillgrønt og blandet selskab**.

**Leitz Eins-Zwei-Zero Rosé** (ca. 75–110 kr): tør stil.  
**Torres Natureo Rosé** (ca. 65–90 kr): blødere, spansk vibe til budget.

Server **8–10 °C**. Mere: [bedste alkoholfri rosé](/guides/bedste-alkoholfri-rose).

## Tør hvid 0 % — til fisk og syrlige bidder

**Leitz Riesling 0 %** eller **Giesen 0 % Sauvignon Blanc** til **rejer, sardiner, salat og citron**. Undgå sød muscat til salt tapas — det kolliderer. Se [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin) · [Riesling 0 %](/guides/alkoholfri-riesling).

## Bobler 0 % — velkomst og «renser»

**Leitz Sparkling**, **Torres Natureo Sparkling** eller **Oddbird Blanc de Blancs** til første glas og til salt snack. Premium: [French Bloom](/guides/french-bloom-alkoholfri-vin). Overblik: [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler).

## Rød 0 % — kun hvis bordet kræver det

Tapas er **sjældent** pinot-territorium hele aftenen. Har du **kødboller, chorizo og pizza-agtige bidder**, tilføj **Torres Natureo Red** eller **Leitz Pinot** — ellers spar rød. Se [alkoholfri Pinot Noir](/guides/alkoholfri-pinot-noir).

## Praktisk setup (4–8 personer)

1. **Én rosé + én bobler** dækker 80 % af et blandet tapasbord.  
2. Tilføj **én tør hvid**, hvis der er meget fisk/citrus.  
3. Køl **alt** — varm 0 % smager fladt.  
4. Budget: [under 100 kr](/guides/bedste-alkoholfri-vin-under-100-kr) · butik: [Netto/Føtex/Bilka/Meny](/guides/alkoholfri-vin-i-netto-foetex).

## Kort valg

- **Klassisk spansk bræt** → Natureo eller Leitz rosé + bobler.  
- **Fisk & skaldyr tungt** → riesling/sauvignon 0 % + bobler.  
- **Fest / gave-tapas** → Oddbird eller French Bloom til velkomst.  
- **Kun kød** → blød rød + bobler som backup.
