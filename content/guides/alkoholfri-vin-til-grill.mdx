## Alkoholfri på grillen — hvad der faktisk virker

**Alkoholfri vin til grill** skal klare **røg, fedme, salt og marinade** — uden alkoholens krop. Det betyder: prioriter **syre, frugt og kølig servering**. De tre stærkeste 0 %-valg til grillbordet er **rosé**, **bobler** og **blød rød** (garnacha/pinot-stil). Tung «cabernet-agtig» 0 % falder ofte igennem mod BBQ-glaze.

Klassisk grill-logik (med alkohol) findes i [vin til grill og BBQ](/guides/vin-til-grill-og-bbq) — her oversætter vi den til **0 %**.

| Grill-mad | Bedste 0 %-valg | Hvorfor |
|-----------|-----------------|---------|
| Kylling, grøntsager, halloumi | Rosé eller frisk hvid | Syre + frugt uden hård tannin |
| Pølser, pizza fra grillen | Blød rød (Torres Natureo Red) | Moden frugt, lav bitterhed |
| Bøf / ribs med BBQ | Bobler eller blød rød + bobler | Kulsyre renser; ærlig rød er svær |
| Fisk / rejer på grill | Hvid (riesling/sauvignon) eller bobler | Syre matcher røg og citron |
| Tapas / blandet bord | Rosé + bobler | Én stil dækker salt, fedme og varme |

## Rosé 0 % — sommerens default til grill

**Alkoholfri rosé** er det mest alsidige grillglas: jordbær, syre, kølig servering. Den tåler **kylling, grøntsager, skinke, let krydderi** og blandet selskab.

**Leitz Eins-Zwei-Zero Rosé** (ca. 75–110 kr): tør stil, jordbær — ikke saft.  
**Torres Natureo Rosé** (ca. 65–90 kr): lidt blødere, god budget-grillvin.

Server **velafkølet (8–10 °C)**. Se [bedste alkoholfri rosé](/guides/bedste-alkoholfri-rose) og [rosévin til grill](/guides/rosevin-til-grill) for principperne (samme logik, med/uden alkohol).

## Bobler 0 % — når røgen og saucen er kraftige

**Alkoholfri bobler** er undervurderet til grill: moussen **renser ganen** mellem bidder med glaze, chili og fedt.

**Leitz Eins-Zwei-Zero Sparkling** eller **Torres Natureo Sparkling** til hverdagsgrill.  
**Noughty / French Bloom** når gæsterne skal føle «fest» uden promille — se [bedste alkoholfri bobler](/guides/bedste-alkoholfri-bobler).

Server **6–8 °C**. Hold flasken i is — varm 0 %-boble smager fladt.

## Rød 0 % til grill — realistiske forventninger

**Alkoholfri rødvin til grill** kan fungere til **pølser, pizza, kylling med skorpe** — ikke som erstatning for ung cabernet til ribeye.

**Torres Natureo Red** (ca. 70–100 kr): blød garnacha-frugt — bedste budget-rød til hverdagsgrill.  
**Leitz Pinot Noir 0 %** (ca. 110–150 kr): mere «vin» til and/kylling med krydderi.

**Trick:** server rød **lidt køligere** end du er vant til (ca. 12–14 °C), og hav bobler som backup hvis glasset føles tyndt. Mere ærlighed: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin).

Til klassisk bøf med alkohol: [vin til bøf](/guides/vin-til-boeff). Til 0 %: start med **rosé eller bobler**, ikke den tungeste 0 %-rød.

## Hvid 0 % til fisk og grønt på grillen

**Grillet laks, rejer, asparges, salat med grillkylling:** vælg **riesling eller sauvignon uden alkohol**.

**Leitz Riesling 0 %** eller **Giesen 0 % Sauvignon Blanc** — syren bærer røg og citron. Detaljer: [bedste alkoholfri hvidvin](/guides/bedste-alkoholfri-hvidvin) og [vin til grillet fisk](/guides/vin-til-grillet-fisk).

## Praktisk grill-setup (blandet selskab)

1. **Én rosé + én bobler** dækker 80 % af en blandet grillmenu.  
2. Tilføj **én blød rød** hvis der er pølser/pizza.  
3. Køl **alt** — 0 % tåler varme dårligere end alkoholisk vin.  
4. Server i **rigtige glas** (ikke plastik) — se [alkoholfri vin til fest](/guides/alkoholfri-vin-til-fest).  
5. Budget under 100 kr: [bedste alkoholfri vin under 100 kr](/guides/bedste-alkoholfri-vin-under-100-kr).

## Hvad du skal undgå på grillen

- **Kun sodavand til «ikke-drikkere»** — 0 % vin føles som del af bordet.  
- **Varm 0 %-rød** i solen — smager af kompott.  
- **Sød festdrik** uden vintype — kolliderer med røg og salt.  
- **Én tung 0 %-rød til hele menuen** — fisk og grønt drukner.

## Kort valg

- **Terrasse + blandet grill** → Leitz eller Torres rosé.  
- **Skål + ribs/BBQ** → bobler (evt. + blød rød).  
- **Fisk på grill** → riesling/sauvignon 0 %.  
- **Kun pizza/pølser** → Torres Natureo Red.
