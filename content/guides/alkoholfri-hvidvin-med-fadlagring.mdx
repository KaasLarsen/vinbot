## Kort svar

**Nej — ikke det samme.** Lidt **eg-agtig rundhed** kan overleve i alkoholfri chardonnay-stil, men klassisk fadlagret hvidvin (Meursault, oaked Rioja blanco) mister det meste **toast, vanilje og viskositet**, når alkoholen fjernes. Forvent **antydning**, ikke kopi.

Læs [alkoholfri chardonnay](/guides/alkoholfri-chardonnay) og [hvad er fadlagring](/guides/hvad-er-fadlagring).

## Hvad fadlagring normalt giver

- Aroma: toast, vanilje, røg, kokos
- Tekstur: fedme, længde
- Integration via alkohol + tid

Uden alkohol mangler **bæreren**. Producenter kan bruge **eg-chips, stave eller kort fadkontakt** før/efter dealkoholisering — resultatet er mildere.

## Hvad du kan forvente i 0 %

| Element | Traditionel fad-hvid | Typisk 0 % |
|---------|----------------------|------------|
| Vanilje/toast | Tydelig | Svag / fraværende |
| Cremet mund | Markant | Let rundhed |
| Syre | Balanceret af alkohol | Skal være høj for at bære |
| Pris | Ofte høj | Noughty-niveau / premium 0 % |

## Praktisk råd

Vil du have **fad-association**: vælg den mest fyldige 0 %-chardonnay (fx Noughty) og server lidt mindre koldt (10–12 °C). Vil du have **vin-oplevelse**: vælg tør riesling/sauvignon — de lykkes oftere.

Til mad med smør/fløde: chardonnay-stil. Til citron/skaldyr: [sauvignon](/guides/alkoholfri-sauvignon-blanc).

## Kort konklusion

Fadlagret 0 %-hvid er et **kompromis**. Smager det «som traditionel»? Kun i grove træk. Køb til rundhed — ikke til eg-show.
