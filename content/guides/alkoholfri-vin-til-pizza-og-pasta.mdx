## Alkoholfri vin til pizza og pasta — hverdagens 0 %-match

**Pizza og pasta med tomat** er det sted, hvor alkoholfri **rød** oftest rammer plet: moden frugt, blød tannin og syre der møder tomaten — uden at glasset smager af sprit eller tynd saft. Vælg **garnacha-/pinot-stil**, ikke tung cabernet-0 %.

Med alkohol: [vin til pizza og pasta](/guides/vin-til-pizza-og-pasta). Ærlig 0 %-rød: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin).

| Ret | Bedste 0 %-valg | Undgå |
|-----|-----------------|-------|
| Margherita / pepperoni | Torres Natureo Red | Anonym «kraftig» 0 %-rød |
| Pasta arrabbiata / bolognese | Natureo Red eller Leitz Pinot | Sød festdrik |
| Pasta pesto / carbonara-agtig | Hvid (chardonnay/riesling 0 %) | Tung rød |
| Pizza bianca / svampe | Leitz Pinot Noir 0 % | For sød rosé |
| Seafood-pasta | Riesling/SB 0 % eller bobler | Rød |

## Garnacha / Natureo Red — pizza-default

**Torres Natureo Red** (ca. 70–100 kr) er den mest realistiske **hverdags-0 %-rød** til tomat: blød garnacha-frugt, lav bitterhed, findes ofte i super. Den «klarer» tomatsyre bedre end mange tynde cabernet-0 %, fordi frugten er **moden og blød** — ikke fordi den har mere alkohol.

Se [Torres Natureo](/guides/torres-natureo) · [under 100 kr](/guides/bedste-alkoholfri-vin-under-100-kr).

## Pinot Noir 0 % — når pizzaen skal føles «vin»

**Leitz Eins-Zwei-Zero Pinot Noir** (ca. 110–150 kr) er opgraderingen: mere kirsebær/krydderi, bedre til **svampe, salami med karakter og ragù**. Detaljer: [alkoholfri Pinot Noir](/guides/alkoholfri-pinot-noir).

**Oddbird Rouge** ligger i samme slot til dem, der vil have designflaske til hyggeaften: [Oddbird](/guides/oddbird-alkoholfri-vin).

## Hvid og bobler — pesto, skaldyr og «let pasta»

- **Pesto, fløde, kylling:** [Noughty](/guides/noughty-alkoholfri-vin) eller Leitz Riesling.  
- **Seafood-pasta:** sauvignon/riesling 0 % — [hvidvin-hub](/guides/bedste-alkoholfri-hvidvin).  
- **Fredags-pizza med gæster:** start med **bobler**, skift til Natureo til hovedretten — [bobler](/guides/bedste-alkoholfri-bobler).

## Hvorfor tung 0 %-cabernet ofte fejler til tomat

Uden alkohol bliver **tannin og egetræsnoter** let hårde, mens tomatsyre forstærker bitterhed. Frugtig, let rød (garnacha/pinot) holder **frugt + syre** i balance. Mere om cabernet/shiraz-stil: [bedste alkoholfri rødvin](/guides/bedste-alkoholfri-rodvin).

## Servering

- Rød **12–14 °C** (kort tid i køleskab).  
- Hvid/bobler **6–10 °C**.  
- Én flaske Natureo dækker typisk **2–3 personer** til pizzaaften.

## Kort valg

1. **Klassisk pizza/tomatpasta** → Torres Natureo Red.  
2. **Svampe / «lidt finere»** → Leitz Pinot.  
3. **Pesto / fiskepasta** → hvid 0 %.  
4. **Blandet selskab** → bobler + Natureo.
