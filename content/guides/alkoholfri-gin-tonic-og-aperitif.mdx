## Når festen ikke kun er vin

Folk der søger **alkoholfri vin til fest**, leder ofte også efter **0 % gin & tonic, spritz og aperitif** som velkomst. Denne guide er **vinhubbens naboside**: spirits-alternativer der passer til samme anledninger — ikke et spirits-leksikon.

Start med vin: [alkoholfri vin til fest](/guides/alkoholfri-vin-til-fest) · [bobler](/guides/bedste-alkoholfri-bobler). Cocktails med vin-base: [vin i cocktails](/guides/vin-i-cocktails-spritz-og-drikke).

| Drik | Typisk brug | Eksempler |
|------|-------------|-----------|
| **0 % gin & tonic** | Velkomst, terrasse | Tanqueray 0.0, Ish Spirits gin |
| **0 % spritz** | Aperitivo, brunch | Lyre’s Italian Orange + bobler |
| **Alkoholfri bobler** | Skål | Leitz, Oddbird, French Bloom |
| **Botanisk «spirit»** | Nørdet G&T | Seedlip, Lyre’s |

## Alkoholfri gin & tonic

**Tanqueray 0.0** er det mest genkendelige supermarket-/bar-navn: klassisk juniper-profil uden alkohol — god når gæsterne bare vil have «en G&T».  
**Ish Spirits** (dansk) ligger i specialty-enden: botanicals og design, der føles som en rigtig bar-drik.

**Sådan serverer du:** højboldglas, masser af is, kvalitets-tonic (ikke den sødeste sodavand), citrusskal. Forhold ca. som vanlig G&T — smag dig frem; 0 % gin kan smage **skarpt** uden alkoholens blødhed.

## Spritz uden Aperol — og med 0 % bobler

Klassisk spritz = bitter + prosecco + soda. Uden alkohol:

1. **Lyre’s Italian Orange** (eller tilsvarende 0 % «Aperol»-stil) + **alkoholfri bobler** + splash soda.  
2. Eller skip bitter: **Natureo/Leitz sparkling** med appelsinskive — simplere, mere «vin».

Bobler-valg: [Leitz / Torres / Noughty](/guides/bedste-alkoholfri-bobler) · premium: [French Bloom](/guides/french-bloom-alkoholfri-vin) · [Oddbird](/guides/oddbird-alkoholfri-vin).

## Sukker og «festdrik»

Mange 0 % spirits og ready-to-drink mixes er **søde**. Til diabetikere / lavt sukker: vælg **tør tonic**, undgå færdig «alkoholfri cocktail» med sirup, og overvej tør 0 %-vin i stedet — [sukker & diabetes](/guides/alkoholfri-vin-sukker-og-diabetes).

## Praktisk fest-setup

1. **Én 0 % gin + tonic + citrus** til ankomst.  
2. **Én kasse alkoholfri bobler** til skål.  
3. **Én still 0 %** (hvid/rosé/rød) til maden.  
4. Mærk flaskerne tydeligt, så ingen blander med alkoholiske spejlinger.

## Kort valg

- **Klassisk G&T** → Tanqueray 0.0 eller Ish + god tonic.  
- **Aperitivo** → 0 % bitter + alkoholfri bobler.  
- **Skål** → vin-bobler, ikke gin.  
- **Usikker** → start med [alkoholfri vin til fest](/guides/alkoholfri-vin-til-fest).
